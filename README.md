# Nirvanaah Premium Rebuild

Modern Next.js 15 recreation of Nirvanaah with premium storytelling, preserved brand content, and conversion-focused sections.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The project is configured for Vercel via `vercel.json`. Connect the repository in Vercel, then set the production domain to `nirvanaah.com`.
